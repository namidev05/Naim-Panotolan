# Web Developer Portfolio Landing Page

A modern UI/UX portfolio landing page built with:

- HTML
- SCSS with nesting
- Compiled CSS
- Vanilla JavaScript

## Files

- `index.html` — Main page structure
- `style.scss` — Editable SCSS source file
- `style.css` — Compiled CSS used by the HTML file
- `script.js` — Menu, smooth interaction, active nav, and reveal animation

## How to Use

Open `index.html` in your browser.

To edit the design, update `style.scss`, then compile it into `style.css`.

Example if you have Sass installed:

```bash
sass style.scss style.css
```

## Customization

Replace these placeholders:

- Developer name
- Developer image
- Project images
- Project links
- Email address
- GitHub / LinkedIn links
- Experience content
